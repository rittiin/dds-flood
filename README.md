# เฝ้าระวังโรคติดต่อในสถานการณ์อุทกภัย ปี 2569

แดชบอร์ดติดตามสถานการณ์โรคติดต่อในช่วงน้ำท่วม จากข้อมูล **Digital Disease Surveillance (DDS)** และ **กรมป้องกันและบรรเทาสาธารณภัย (ปภ.)**

🔗 **เปิดใช้งาน:** <https://ddsflood.pages.dev>

![ภาพหน้าจอ](docs/screenshot.jpg)

---

## ฟีเจอร์

| แท็บ | เนื้อหา |
|---|---|
| สถานการณ์ภาพรวม | แนวโน้มผู้ป่วยรายใหม่ตามวันเริ่มป่วย (รายวัน / เฉลี่ย 7 วัน), สัดส่วนผู้ป่วยตามกลุ่มโรค, 10 จังหวัดอัตราป่วยสูงสุด |
| วิเคราะห์รายโรค | สรุปรายโรค เทียบ 7 วันล่าสุดกับ 7 วันก่อนหน้า (ดาวน์โหลด CSV ได้) |
| รายพื้นที่ | แยกตามเขตสุขภาพ / จังหวัด |
| รายวัน/สัปดาห์ | แนวโน้มตามช่วงเวลา |
| รายงานสถานการณ์ / พิมพ์รายงาน | สรุปพร้อมพิมพ์ |

- **ตัวกรอง:** เขตสุขภาพ, จังหวัด, ช่วงวันเริ่มป่วย (30 วัน / 90 วัน / ทั้งปี)
- **ปฏิทินเฝ้าระวังหลังน้ำท่วม:** ช่วงเวลาที่แต่ละโรคมักปรากฏ นับจากวันที่น้ำเริ่มท่วม (0–42 วัน)
- **อัปเดตข้อมูลอัตโนมัติ** วันละ 3 ครั้ง (07:30, 11:30, 19:30 น.)
- **ช่องทางแจ้งปัญหา/ข้อเสนอแนะ** และแบบประเมินความพึงพอใจ
